Allbox Privacy Policy

Last updated: 6 November 2026. Back to Allbox

What Allbox accesses

With the user's consent, Allbox connects to Gmail through Google's Gmail API, using the gmail.modify permission. It can read, send, label, archive and trash mail in the signed-in account. It cannot permanently delete mail.

How the data is used

Gmail data is used only to show and manage the user's own mail in the app. It is not used for advertising, analytics or training any AI model.

Where the data is stored

Allbox has no server. Sign-in tokens and a cache of recent mail are stored on the user's own PC, encrypted. The developer cannot see them.

Who the data is shared with

Nobody. Data moves only between the user's PC and Google. It is not sold, and it is not sent to the developer or any other party.

One exception, on the user's click: images in a mail are blocked until the user clicks "Load images" on that mail. The click asks the servers named in that mail for its images, which shows those servers the PC's internet address, as any mail program does. No Gmail data is sent to them.

Google API Services

Allbox's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and data

A user can remove Allbox's access at any time in their Google Account permissions. The data stored on the PC stays there until the folder %LOCALAPPDATA%\Allbox is deleted. Deleting the program alone does not remove it.

This website

These pages are hosted on GitHub Pages. They set no cookies and contain no tracking. GitHub may log visitors' IP addresses to run its service, as described in its own privacy statement.

Contact

Questions go to the support email shown on Google's sign-in screen for Allbox.
